# SynapVine Web

Interactive 3D knowledge graph visualization of AI concepts. Built with Vue 3, TypeScript, Vite, and shadcn-vue.

## Tech Stack

- Vue 3 + TypeScript
- Vite
- Tailwind CSS v4
- shadcn-vue
- 3d-force-graph (Three.js)
- vue-i18n

## Development

```bash
bun install
bun run dev
```

Dev server runs at `http://localhost:5173`.

```bash
bun run build
```
